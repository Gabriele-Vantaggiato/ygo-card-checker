# Card Embedding Recognition Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Recognise physical cards in the Collezione live scan from their image (DINOv2-small embeddings + precomputed int8 index), with a sharpness gate, multi-frame voting, a top-5 candidate strip, and an optional Gemini "Leggi con AI" fallback.

**Architecture:** Spec: `docs/superpowers/specs/2026-10-26-card-embedding-recognition-design.md` (read it first). The index format, the Node recipe (`tools/card-index/embedder.mjs`) and the builder already exist on this branch (commit 2df2aad). This plan adds the browser runtime: pure utils (sharpness, voting, art-box geometry), `CardIndexService`, an embedding Web Worker + `CardEmbeddingService`, the recognizer integrated into `CollectionScannerService`, the UI, and the AI fallback.

**Tech Stack:** Angular 20 (standalone, signals, OnPush), `@huggingface/transformers` 3.8.1 in a Web Worker (existing pattern: `src/app/services/decision/card-decision.service.ts` + `card-decision.worker.ts`, `tsconfig.worker.json` already includes `src/**/*.worker.ts`), Karma/Jasmine, DaisyUI.

## Global Constraints

- Branch `feature/card-embedding-recognition` (do not push or merge; the controller does).
- Browser recipe MUST equal `tools/card-index/embedder.mjs`: input squashed to 224x224 (no centre crop), ImageNet mean/std taken from the model's processor config (`onnx-community/dinov2-small`), model `dtype: 'q8'` on WASM (or `fp16` when WebGPU is available), vector = `[L2(CLS), L2(mean of patch tokens)]` then L2 of the 768-d concatenation, **batch size 1**, art box `x 0.11..0.89, y 0.18..0.72`.

### Task 1: Pure utils (geometry, sharpness, voting, preprocessing)

**Files:**
- Modify: `src/app/utils/scan-geometry.utils.ts` (+ spec `scan-geometry.utils.spec.ts`)
- Create: `src/app/utils/sharpness.utils.ts`, `src/app/utils/frame-vote.utils.ts`, `src/app/utils/embedding-preprocess.utils.ts` and their `.spec.ts`

**Interfaces — Produces (exact):**

```ts
// scan-geometry.utils.ts (additions)
export interface Box { x0: number; x1: number; y0: number; y1: number }
export const ART_BOX: Box = { x0: 0.11, x1: 0.89, y0: 0.18, y1: 0.72 };
/** Pixel rectangle of a fractional box inside a w x h frame (rounded, clamped to >= 1 px). */
export function cropRect(w: number, h: number, box: Box): { sx: number; sy: number; sw: number; sh: number };

// sharpness.utils.ts
/** Variance of the 4-neighbour Laplacian over the luminance of an RGBA image (higher = sharper). */
export function laplacianVariance(rgba: Uint8ClampedArray, width: number, height: number): number;
export const SHARPNESS_THRESHOLD: number;          // tuned constant, see Step 3
export function isSharp(variance: number, threshold?: number): boolean;

// frame-vote.utils.ts
export interface FrameHit { id: number; score: number }
export interface VotedCandidate { id: number; score: number; votes: number }
export interface VoteResult { candidates: VotedCandidate[]; confident: boolean; framesUsed: number }
export class FrameVoter {
  constructor(options?: { windowSize?: number; minFrames?: number; minMargin?: number });
  push(hits: readonly FrameHit[]): VoteResult;   // hits = top-K of ONE sharp frame, best first
  reset(): void;
}

// embedding-preprocess.utils.ts
export const MODEL_INPUT_SIZE = 224;
/** Squash-resize (bilinear) an RGBA region to 224x224 and return normalised CHW floats. */
export function rgbaToChw(rgba: Uint8ClampedArray, width: number, height: number, mean: readonly number[], std: readonly number[]): Float32Array;
/** [L2(cls), L2(meanPatch)] then L2 of the concatenation; tokens = last_hidden_state data [1, t, d]. */
export function poolTokens(tokens: Float32Array, tokenCount: number, dim: number): Float32Array;
```

`FrameVoter` semantics (specify and test): keeps the last `windowSize` (default 5) frames; per card id sums the scores (`score` = fused cosine sum) and counts `votes` (frames where the id was in that frame's hits); candidates sorted by summed score / framesUsed descending; `confident` = framesUsed >= `minFrames` (default 3) AND the top candidate appears in at least `minFrames` frames AND (top mean score - second mean score) >= `minMargin` (default 0.05) ; `reset()` clears history.

- [ ] **Step 1: Write the failing specs** — cover: `cropRect` (art box of 1000x1400, clamps, rounds), `laplacianVariance` (flat image => 0; checkerboard > a blurred copy; a sharp edge image > its 3x3 box-blurred version — build synthetic RGBA arrays in the spec), `isSharp`, `FrameVoter` (single frame never confident; three consistent frames confident; two competing ids with a tiny margin not confident; window eviction; reset), `rgbaToChw` (uniform colour image => each channel plane equals `(v/255-mean)/std`; output length 3*224*224; non-square input works), `poolTokens` (CLS and mean halves each unit-norm before the final normalisation, output unit length, dim 2*d; compare to a hand-computed tiny example with d=2, t=3).
- [ ] **Step 2: Run them, see them fail** (modules missing).
- [ ] **Step 3: Implement** the signatures above. `laplacianVariance`: luminance `0.299R+0.587G+0.114B`, kernel `[0 1 0; 1 -4 1; 0 1 0]` over interior pixels, return variance of the response. `SHARPNESS_THRESHOLD`: choose by measurement — in the spec or a one-off script, compute the variance of a real card image from the cache (`C:\Users\adani\AppData\Local\Temp\claude\C--Users-adani\1d759731-9806-42a8-a5bb-05a0eebbe911\scratchpad\ci-cache\img\`, load with `sharp`) at 224 px width, sharp vs the "harsh" blur (sigma 1.5) and set the threshold between them (document the numbers in a code comment). `rgbaToChw`: bilinear squash resize to 224x224 on the RGBA region, alpha ignored. `poolTokens` mirrors `tools/card-index/embedder.mjs` (lines of `embed()` after the model call).

### Task 2: Index service, embedding worker and service

**Files:**
- Create: `src/app/services/card-index.service.ts`, `src/app/services/embedding/card-embedding.worker.ts`, `src/app/services/embedding/card-embedding.service.ts`

**Interfaces:**
- Consumes: `decodeIndex`, `searchIndex`, `CardIndex` from `card-index.format.ts`; `rgbaToChw`, `poolTokens`, `MODEL_INPUT_SIZE` from `embedding-preprocess.utils.ts`.
- Produces:

```ts
// CardIndexService (providedIn root)
readonly state: Signal<'idle' | 'loading' | 'ready' | 'error'>;
readonly progress: Signal<number>;            // 0..1 while loading
readonly index: Signal<CardIndex | null>;
readonly version: Signal<string | null>;      // meta.recipe/version for diagnostics
load(): Promise<void>;                        // idempotent; fetch assets/card-index/card-index.bin with streaming progress; 404 => state 'error'
search(full: Float32Array, art: Float32Array | null, k: number): { id: number; score: number }[];   // throws if not ready

// CardEmbeddingService (providedIn root)
readonly state: Signal<'idle' | 'loading' | 'ready' | 'error'>;
readonly progress: Signal<number>;            // model download 0..1
readonly backend: Signal<'webgpu' | 'wasm' | null>;
load(): Promise<void>;                        // idempotent; creates the worker lazily
embed(frame: { rgba: Uint8ClampedArray; width: number; height: number }, art: { rgba: Uint8ClampedArray; width: number; height: number }): Promise<{ full: Float32Array; art: Float32Array }>;   // serialises calls (one in flight); rejects if not ready
dispose(): void;
```

- [ ] **Step 1:** Implement `CardIndexService` (fetch with `ReadableStream` reader for progress when `content-length` is known, else indeterminate; `decodeIndex`; errors set `state='error'` and are logged). No unit test required beyond a tiny spec that stubs `fetch` with an encoded 3-row index (`encodeIndex` from the format module) and checks `state`, `search` result and the 404 path.
- [ ] **Step 2:** Implement the worker following `card-decision.worker.ts` conventions. Messages: `{type:'load'}` -> progress events (`progress_callback` of transformers.js) then `{type:'ready', backend}`; `{type:'embed', id, full:{rgba,width,height}, art:{...}}` -> `{type:'embedded', id, full:Float32Array, art:Float32Array}` (transfer buffers); errors as `{type:'error', id?, message}`. Use `rgbaToChw` with the processor's `image_mean`/`image_std`, run the model with batch 1 (two sequential calls for full and art), pool with `poolTokens`.
- [ ] **Step 3:** Implement `CardEmbeddingService` (worker factory via `new Worker(new URL('./card-embedding.worker', import.meta.url), { type: 'module' })`, promise-per-request map, single in-flight queue, progress/backend/state signals, `dispose()` terminates the worker).

### Task 3: Recognizer pipeline in the scanner service

**Files:**
- Modify: `src/app/services/collection-scanner.service.ts`, `src/app/models/collection.model.ts`
- Test: extend pure tests only (voting already covered); the tick loop is verified by build + manual use.

**Interfaces:**
- Consumes: `CardIndexService`, `CardEmbeddingService`, `FrameVoter`, `laplacianVariance`/`isSharp`/`SHARPNESS_THRESHOLD`, `ART_BOX`/`cropRect`, existing `CardsetLookupService`, `parseSetCode`.
- Produces: `ScanCandidate { card: YgoCard; score: number }`; `ScanDetection.alternatives: ScanCandidate[]` (empty for OCR-sourced detections) and `ScanDetection.source: 'code' | 'name' | 'image'`; new signals on `CollectionScannerService`: `phase: Signal<'loading-model' | 'loading-index' | 'blurry' | 'recognising' | 'ready' | 'ocr-fallback'>`, `sharpness: Signal<number>`, `lastCandidates: Signal<ScanCandidate[]>`.

Behaviour:
1. On `start()`, kick off `CardIndexService.load()` and `CardEmbeddingService.load()` (do not block the camera). While either is not ready, `tick` uses the existing OCR pipeline unchanged and `phase` reflects loading/`ocr-fallback`.
2. When both are ready, each tick: grab the guide frame (existing `grabFrame`), read RGBA of the full frame and of the art box (`cropRect(ART_BOX)`) via `getImageData`; compute `laplacianVariance` on a 224-px-wide copy; if not `isSharp` set `phase='blurry'`, `sharpness`, skip embedding this tick. Else `embed` (skip if one is already in flight), `CardIndexService.search(full, art, 5)`, `FrameVoter.push(hits)`; set `lastCandidates` lazily (resolve ids to `YgoCard` through `YgoApiService.getCardsByIds$` with a small id->card cache; never block the loop on it).
3. When the voter is `confident`: resolve the top card, optionally run the set-code OCR pass on the current frame (same code as today, wrapped so a failure never blocks) to pick the printing from `card.card_sets` filtered by the parsed `setCode`; emit a `ScanDetection` with `source:'image'`, `needsReview` true unless OCR confirmed exactly one printing, `alternatives` = the other voted candidates. Reset the voter and apply the existing cooldown logic (reuse `ScanConsensus` semantics for "same card still in view": do not re-emit the same card id until the frame was non-matching/blurry for >= 1500 ms).
4. When not confident for >= 2.5 s of sharp frames, set `lastCandidates` so the UI can offer the strip (no detection is emitted).
5. Keep all existing race protections (runId checks after every await, stale-run stop). Keep the `debug` signal, extending it with `top5: string` (id:score list) and `sharpness`.

- [ ] **Step 1:** Implement the above. Add small pure helper(s) if useful (e.g. `shouldOfferCandidates`) with specs.
- [ ] **Step 2:** `npx ng build --configuration development` passes; run `npx ng test --watch=false --browsers=ChromeHeadless --include='src/app/utils/**/*.spec.ts'` and report the count (all pass).
- [ ] **Step 3: Commit** `feat(scan): image-embedding recognition in the scanner pipeline`.
